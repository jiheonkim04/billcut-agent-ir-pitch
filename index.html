5. Deployment Decision · 정확한 실행 위치

Pi는 게이트웨이만, 계산은 클라우드?
실제 구조는 로컬 우선입니다.

DEVICE / PROTOCOL EDGE

Raspberry Pi

  • Mosquitto MQTT broker
  • Home Assistant · P110M 로컬 연동
  • 장치 상태·명령의 항상 켜진 진입점
  • 구성에 따라 API·SQLite도 함께 실행 가능
LOCAL DECISION BACKEND

Pi 또는 로컬 노트북

  • FastAPI · SQLite · Telemetry 저장
  • Python 누진요금·시나리오 계산
  • 승인·안전정책·장치 driver 호출
  • 인터넷이 없어도 핵심 기능 유지
OPTIONAL EXTERNAL CLOUD

OpenAI Responses API

  • 자연어 질문 이해
  • 상황에 맞는 도구 선택
  • Python 결과를 사용자 언어로 설명
  • 실패·키 부재 시 offline fallback
검토 결론: 요금 계산을 클라우드에 맡긴 구조가 아닙니다. 실제 제어 경로와 DB는 로컬이며, Pi와 노트북의 분리는 성능보다 장치 게이트웨이의 안정성과 발표·개발 편의성을 위한 배치 선택입니다.

BILL-CUT AGENT = LLM + ORCHESTRATION + LOCAL TOOLS
